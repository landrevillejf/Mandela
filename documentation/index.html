Project Mandela

An embeddable, zero-dependency scripting language for the JVM: a lexer, parser, bytecode compiler, stack VM, capability-gated runtime, standard library, JSR-223 engine, embedding API and CLI/REPL, in one jar. It originated in the Project Looking Glass desktop and is still embedded there, but this repository stands alone and the same jar runs wherever a JVM does.
